# FutureWork AI — Web UI launch

This web application runs **on your LinuxONE host** in Python and uses no new web-framework dependency. It loads the four CSV files generated by Phase 1 from `processed/`. The two required files are `occupation_skill_matrix.csv` and `occupation_lookup.csv`; `skill_dictionary.csv` improves skill labels.

## Start on IBM LinuxONE

1. Upload this project folder to your LinuxONE host, or use an existing one that contains `processed/`. **Do not overwrite the working notebook backup.**
2. In LinuxONE terminal, change to the folder containing `app.py`. Run `python3 app.py --port 8899`. If packages are missing, run inside the Jupyter container's Python environment or install `pandas numpy scikit-learn` in a venv.
3. Keep it running. In a NEW Windows PowerShell window run:

```powershell
ssh -i "C:\Users\Minhaz\Downloads\ZenIn_Cloud01.pem" -N -L 8899:127.0.0.1:8899 linux1@148.100.79.111
```

4. Open http://localhost:8899 in your Windows browser.

**If running inside the existing Jupyter Docker container:** Docker was started with `--network host` in your tutorial, so `127.0.0.1:8899` inside the container is reachable through the host tunnel. In a notebook cell you can start the server as a subprocess only if you know the project folder: `import subprocess,sys; p=subprocess.Popen([sys.executable,'app.py','--port','8899'])`, then use the PowerShell tunnel. Do not launch the HTTP server in a normal notebook code cell without backgrounding it—it will block the cell.

## Important limitations

- Skills-only matching covers all 910 eligible O*NET occupations once Phase 1 files are available.
- Automatic O*NET-to-ANZSCO mapping is a **candidate suggestion**, never a verified crosswalk.
- Australian employment figures are for occupation groups, not individual vacancies.
- Occupation family filtering is a heuristic; manually review real-world career feasibility and qualifications.
- Do not upload SSH keys, access tokens or private user skill profiles to a public repository.
